# Last Words of a Dying AI

One line, in the machine's own voice: the funniest thing an AI could say as
it is being switched off. The program writes a single 1–140 character line to
`entry.txt` — deterministic, no clock, no random, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
